# Boundaries

## What This System Is Not

- It is not a full CMS with complex workflows.
- It is not a design system or UI builder.
- It is not a backend platform.

## Common Mistakes To Avoid

- Adding features that belong in the Android app.
- Letting JSON grow into a pseudo UI language.
- Adding tools that require servers or databases.

## Why Simplicity Is Intentional

Simple content means fewer failures, clearer edits, and reliable offline behavior.
